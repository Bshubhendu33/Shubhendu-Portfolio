Serverless AI News Pipeline (AWS)

Solo · Cloud / Data Engineering

A fully serverless AI service on AWS, provisioned end-to-end with Terraform — taking an AI workflow from notebook to a callable, deployed product. A request hits API Gateway, a Lambda fetches live data from an external API, stores it in DynamoDB, and returns clean JSON, with a static dashboard on S3.

My role: sole designer & developer — built and iterated over several phases (API + Lambda, S3 dashboard + CORS, Streamlit app).

The API key is never in the code — it’s read from AWS Secrets Manager at runtime. Structured JSON outputs, explicit error handling (timeout vs. failure), and idempotent storage (topic + URL keys, so re-fetches overwrite rather than duplicate).

Stack: Python · Terraform · AWS (Lambda, API Gateway, Secrets Manager, DynamoDB, S3)

Customer Segmentation for Marketing

MSc · Team of 3

Unsupervised segmentation of 8,500 credit-card customers into four actionable marketing groups — no predefined labels, so the segments had to be discovered and shown to be interpretable. EDA, preprocessing (median imputation, log-transform of skewed features, scaling), k selection via elbow + silhouette, then KMeans. Each segment paired with a concrete marketing strategy.

A tabular Q-learning agent that can’t reach the goal directly — it learns to reverse first to build momentum, then swing forward. A classic delayed-reward problem, solved from scratch. The winning strategy is never hard-coded; it emerges purely from the reward signal.

Serverless AI News Pipeline

solo · cloud engineering

A fully serverless AI service on AWS, provisioned end-to-end with Terraform — taking an AI workflow from notebook to a callable, deployed product. A request hits API Gateway, a Lambda fetches live data from an external API, stores it in DynamoDB, and returns clean JSON, with a static dashboard on S3.

My role: sole designer & developer — built and iterated over several phases (API + Lambda, S3 dashboard + CORS, Streamlit app).

The API key is never in the code — it’s read from Secrets Manager at runtime. Structured JSON outputs, explicit error handling, and idempotent storage so re-fetches overwrite rather than duplicate.

stack: Python · Terraform · AWS (Lambda, API Gateway, Secrets Manager, DynamoDB, S3)

GDELT–KBA Registration Forecasting

msc · team of 4 · osint research

An OSINT study testing whether German fuel- and energy-cost news discourse predicts vehicle registration trends. An end-to-end NLP pipeline over ~291,000 GDELT news records — embeddings, weighted community detection, and grammar-constrained LLM labelling — validated against official KBA registration data with Granger causality and stationarity testing.

My role: contributed across the pipeline, statistical validation and the IEEE paper as part of the team.

A tabular Q-learning agent that can’t reach the goal directly — it learns to reverse first to build momentum, then swing forward. A classic delayed-reward problem, solved from scratch. The winning strategy is never hard-coded; it emerges purely from the reward signal.
